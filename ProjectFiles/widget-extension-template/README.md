# Body&Code Widget Extension

Template files for a Home Screen widget that shows:
- current workout
- progress (completed sets / total)
- remaining sets
- elapsed workout time

## Setup in Xcode
1. Add target: `File -> New -> Target -> Widget Extension`.
2. Name it, for example, `BodyCodeWidgetExtension`.
3. Delete autogenerated widget files in that target.
4. Add these files from this folder to the widget target:
   - `BodyCodeWidgetBundle.swift`
   - `WorkoutProgressWidget.swift`
5. In **Signing & Capabilities** for both targets (`BodyCodeApp` and widget target), add **App Groups**:
   - `group.Wowgorno.BodyCodeApp`
6. Build and run app once, start a workout, then add widget on the iPhone Home Screen.

## Data source
The app writes `WorkoutWidgetSummary` into shared `UserDefaults(suiteName: "group.Wowgorno.BodyCodeApp")` under key:
- `workout_widget_summary_v1`
